# Sentra — AI Security & Testing Platform

Sentra finds, evidences, fixes, and re-verifies security weaknesses in LLM-based
applications (chatbots, RAG systems, tool-using agents) that you own or are
authorized to test.

**Core loop:** Register target → Map attack surface → Threat model → Test →
Evidence → Risk score → Remediate → Retest (before/after).
